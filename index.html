About

Linux software management, kept simple.

Zeri was created to provide a straightforward graphical way to manage applications on Linux. No complicated interface, no unnecessary features and no terminal commands required for everyday use.

It is primarily developed for Raspberry Pi OS and Debian-based Linux distributions.

Installation

Install from the terminal

After downloading the package: 

sudo apt install ./zeri_1.0.0_arm64.deb

Zeri can then be launched from your application menu or with: 

zeri
