## About

**Zeri** is a lightweight graphical application manager for Linux.

It provides an easy way to view installed applications, search through them and uninstall applications without requiring users to work directly with the terminal.

Zeri is designed with simplicity in mind and is particularly suited for Raspberry Pi and Debian-based Linux systems.

## Features

- 🔍 Search installed applications
- 📦 Discover installed applications
- 🖼️ Application icons
- 🗑️ Uninstall applications
- 🧠 RAM usage
- ⚙️ CPU information
- 💾 Disk usage
- ⏱️ System uptime
- 🖥️ Clean graphical interface
- 🐧 Designed for Linux

## Supported Platforms

Zeri is primarily developed and tested on:

- Raspberry Pi OS
- Debian-based Linux distributions
- ARM64 Linux systems

### Architecture

Currently supported:

- `arm64`

More architectures may be supported in the future.
